# Arabic Handwritten Characters Classification

This repository contains a Google Colab project for classifying Arabic handwritten characters using Naive Bayes, with and without PCA for dimensionality reduction.

## Project Structure
- `data/`: Contains the raw CSV datasets for training and testing images and labels.
- `src/`: Intended for Python source code files.
- `requirements.txt`: Lists the Python dependencies required to run the project.
- `README.md`: Project overview and instructions.

## Data
The `data/` directory contains the following CSV files:
- `csvTrainImages 13440x1024.csv`: Training image pixel data.
- `csvTrainLabel 13440x1.csv`: Training image labels.
- `csvTestImages 3360x1024.csv`: Test image pixel data.
- `csvTestLabel 3360x1.csv`: Test image labels.

## Setup
To run this project, clone the repository and install the dependencies:

```bash
pip install -r requirements.txt
```
